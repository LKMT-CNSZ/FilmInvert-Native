1. 软件定位

FilmInvert Native 是在 Windows 本机运行的胶片数字化修片软件。它把相机翻拍或扫描得到的负片图像转换为正像，并把片基、密度跨度、白平衡、明暗色彩、几何、局部修复与导出组织在同一个原生桌面工作流中。处理以浮点图像和密度域反相为基础，成品可输出带 ICC 的 16bit RGB TIFF，同时保存可追溯的 JSON 配方。

界面保留黑白灰的极简“暗房”风格：中央大图、右侧调色、底部照片或胶片帧导航；常用裁切、画线校直、四角透视、片边与切帧入口放在顶部。面板可以停靠和浮动，布局记忆后可从「视图 → 恢复暗房布局」复位。

软件适合胶片摄影爱好者、相机翻拍用户、扫描整理人员，以及需要逐帧精修和批次复核的小型工作室。典型场景包括彩色负片去色罩、黑白负片转换、整条 TIFF/扫描容器拆帧、多张 RAW 独立反相、同卷分组统一风格、建立可恢复的照片库与导出队列。

软件读取原片并记录参数，不在原片内写入评级或编辑。照片库登记路径而不自动复制原片；工程也主要引用原片。日常使用不需要上传照片、不需要网络账户，界面不依赖浏览器或本地 HTTP 服务。它不是扫描设备驱动，也不承担相机联机拍摄、底片物理修复或专业设备色准认证。

2. Windows 环境与随包运行时

发行对象是 Windows 10/11 x64。其他系统、32 位 Windows 和原生 ARM64 版本不在本次交付范围；本次验证只覆盖当前 Windows 电脑，不能据此保证所有 Windows 10/11 组合。软件使用 CPU 处理与 Qt Widgets 原生界面，不要求另装 Python、Qt 或浏览器运行环境，也没有必须使用独立显卡的前提。

两种发行包都包含独立的官方 CPython 3.13.17、NumPy 2.3.5、Pillow 12.3.0、rawpy 0.27.1、PySide6 Essentials / Shiboken6 6.12.0。版本、官方下载来源与依赖 SHA256 在 dependencies.json 中，许可和 notices 在 THIRD_PARTY 中。运行时与应用源码保持分离，Qt 动态库可按许可要求以兼容版本替换。

硬件建议属于使用建议，并非本次测得的最低门槛：一般单幅图像建议有 8 GB 或以上内存、SSD 和足够的导出空间；大幅扫描、150 MP 级原片或边修片边导出建议 16–32 GB 或更多。一个 RGB float32 原图数组约占宽×高×12 字节，处理临时数组、Qt 显示、预览和独立导出进程会继续占内存。请按实际原片大小选择并行操作强度。

4. 输入格式及边界

RAW 扩展名入口包括 CR2/CR3/CRW、NEF/NRW、ARW/SRF/SR2、DNG、RAF、ORF、RW2、PEF、SRW、RAW/RWL、3FR/FFF、ERF/MEF/MOS/IIQ、K25/KDC/DCR。实际能否解码由随包 rawpy/LibRaw、相机型号和容器内容决定；扩展名在列表中不等于所有机型、压缩和变体均已验证。真实 NEF 和部分大扫描已有本机记录，其他相机需要实际样本确认。

常规图像支持 TIF/TIFF、PNG、JPG/JPEG、BMP、WebP。RAW 以线性、16bit 解码结果进入处理，禁用 RAW 自动提亮；白平衡优先采用解码器 daylight 固定增益，缺少有效值才回退到相机白平衡。FFF/3FR 在 RAW 解码不支持时可尝试读取其 TIFF 容器；并非所有 FFF/3FR 都是能这样读取的扫描 TIFF。

16bit RGB TIFF 有专用读取路径，避免经常规 8bit 显示接口损失精度。当前专用 TIFF 路径以经典 TIFF、条带、交错 chunky 布局为主，支持灰度/RGB/RGBA、8/16bit、II/MM 字节序及无压缩、LZW、Deflate、PackBits。RGBA 丢弃 alpha。BigTIFF、tiled、planar 分离、CMYK、浮点、多页堆栈或其他未覆盖变体不应视为保证支持；遇到错误可先用可信工具转换为标准 16bit RGB TIFF，并保留正确色彩编码。CMYK 和透明度合成不属于正式色彩工作流。

输入色彩可选：自动优先嵌入 ICC、兼容旧版、线性 sRGB、sRGB 编码、Adobe RGB (1998) 编码、ProPhoto RGB 编码。兼容模式将 16bit TIFF 视作线性，将 8bit 图像视作 sRGB。已经带 gamma 的 16bit 文件必须明确选择其编码或受支持的 ICC，否则明暗和反相密度会解释错误。8bit JPEG 能使用，但已有压缩、量化和剪裁无法逆转，优先采用充分曝光且不过曝的 RAW/16bit 扫描。

输入 ICC 支持 v2/v4 RGB matrix/TRC 类配置；LUT 扫描仪配置、CMYK 或其他不支持的配置会明确拒绝，应先转换到已知 RGB 工作空间。改变输入解释或工作空间相当于重新解释原片，要重新检查调色；软件提供受影响编辑的备份提示。

5. 第一次完成一张照片

  1. 启动软件，在顶部选择「单张」或「自动识别」，按 Ctrl+O 打开原片，也可直接拖到画布。顶部打开方式作用于下一张；当前图像在「片边辅助 / 切帧」里修改。
  2. 核对输入编码与工作空间。彩色负片选择「彩色负片」，黑白负片选「黑白负片」；正片或已转正的图像使用「正片」。先确认方向和单张/整条是否识别正确。
  3. 查看自动片基与跨度。若有未曝光片边，使用「点片基」取样；再根据画面调整密度跨度、反差、曝光、黑白场。取样应避开片夹、污点、剪裁高光和图像主体。
  4. 彩色图用中性灰取样、温度/色调及 RGB 增益调整白平衡；随后调曲线、HSL、饱和度。不要以同一个曝光值强套所有翻拍。
  5. 先在片边/切帧里确定输入区域，再在裁切工作台调构图、画线校直、四角透视；Ctrl+J 进行局部精修。按 F 适应，Ctrl+1 检查全尺寸细节。
  6. 按 Ctrl+Alt+S 保存 .filmproj 工程，保留可恢复的完整编辑；需要风格复用时另存配方。选择输出空间与输出目录。
  7. Ctrl+Shift+S 导出当前帧的 16bit TIFF 与 JSON。打开成品确认方向、边缘、尘点与色彩；需要后续调整时继续用工程及原片，而不是从成品反推编辑。

随包 app/samples 只包含合成演示图、参考 CSV 和演示工程。可打开 calibration-demo.filmproj 观察色卡恢复，或用 pro-strip-demo.tif 练习整条导航；合成样例不构成真实胶片效果或色准证明。

6. 片基、测光与调色

彩色负片先将线性透射值转到密度域，再逐通道扣除片基以处理色罩，结合跨度、反差和胶片矩阵反相。内置 22 种胶片风格矩阵用于调色起点，不等同于逐型号实测的物理胶片档案。黑白模式合成单通道后反相，不应用彩色色卡校正；正片模式用于无需负片反相的图像。

自动片基和自动测光是起点：画面内容、残留片边、遮挡和曝光会影响估计。片基任一通道接近解码端点时，软件会警告/拒绝不可信取样；拍摄时保留通道余量比后期修复更可靠。「点黑场」配合片基帮助设定密度跨度，「点中性灰」帮助校正整体偏色。自动白平衡是画面估计，缺少中性内容、强烈单色光或剪裁时需要人工调整。

基础页包括反差、密度跨度、曝光、黑白场、色温/色调、通道增益等；曲线/HSL 页提供共用 RGB 明暗曲线和八色 HSL。曲线双击增删点、拖动调整，Delete 删除选中的内点。显示原负片可按当前几何位置来回比较。

欠曝通道修复根据其他通道推断受损信息，只是估计，不会恢复已丢失的真实颜色。孤立尘点修复按可见光图像估计，可能改变小细节，缩图与全尺寸检测不同。暗角和平场可缓解照明不均；参考平场应与原片同尺寸、方向和光路，整条平场利用间隙估计横向照明，均不能代替拍摄端均匀照明。

撤销 Ctrl+Z、重做 Ctrl+Shift+Z 或 Ctrl+Y，主窗口最多保留 50 步，连续拖动合并记录。撤销历史不随工程保存，切帧后不会恢复上一帧的操作历史。

7. 裁切、多参考线校直、片边与四角透视

「裁切」或 Ctrl+R 打开几何工作台。支持自由和常见固定比例、90° 转向、±15° 小角度校直、百分比边界与结果尺寸预览。90° 旋转和整数裁切无需插值，小角度/透视需要重采样，输出保持浮点处理后生成 16bit 文件。长条图校直后为了去掉空边可能明显收窄，请检查可用范围。

「画线校直」允许连续添加多条水平/竖直参考线；可选择线段、拖动端点、删除或清空。有效线按原图像素长度加权求一个综合角度，太短或超范围的线不采用。它求的是整体旋转角度，不会分别弯曲画面去贴每条线。临时参考线仅属于本次对话框，工程保存最终角度；重开后可重画。

「片边辅助 / 切帧」或 Ctrl+Shift+R 在原始扫描概览中管理输入片框。可查看倾角建议并明确采用，也可「沿片边画线」用多条线测角。各帧有各自的参考线与输入角度，「采用到同条」只传递综合角度；最终需点「应用输入与切帧」。输入片框决定从扫描中切出哪一帧，成品裁切决定该帧最后保留多少，两者用途不同。

「四角透视」在同一平面上调整左上、右上、右下、左下四角，可指定输出比例并实时比较。适合翻拍不平行造成的梯形，不会纠正镜头畸变或弯曲底片的非平面形变。四角不应交叉或退化。四角、比例、裁切和校直随工程/配方保存，清除透视可以保留其他几何设置。

8. 局部修复

Ctrl+J 打开局部精修，提供仿制修复、曝光笔刷、线性渐变。仿制先 Alt+单击选择来源，再拖画覆盖尘点/划痕；曝光笔刷设定 EV、半径、羽化和强度；渐变从无调整端拖向完整调整端。仿制来源越出画面的部分不处理。

编辑画布基于裁切前、未翻转的当前帧；输出时按参数应用到正确位置。可撤销/重做笔画、开关局部编辑比较，最多 256 笔。局部修复是手动仿制与曝光调整，没有生成式补画、AI 语义选区或红外除尘。它保留每帧编辑，批次风格同步不会把另一张的瑕疵位置复制过来。

9. 宽色域、ICC 与色卡

内部工作空间可选线性 sRGB 或线性 ProPhoto。工作空间决定运算所用 RGB 基础，TIFF 输出空间决定成品编码及嵌入 ICC，两者应分开理解。输出支持 sRGB、Adobe RGB (1998)、ProPhoto RGB；输出 ProPhoto 不能恢复在较早环节已剪裁或未采集到的颜色。

视图菜单可选择显示器 RGB ICC；未指定时按默认 sRGB 显示。输出 RGB 色域预览用于查看所选输出空间影响，J 切换目标输出越界：红色高于上界、蓝色低于下界、紫色同时发生。它表示成品编码前的目标 RGB 越界，不能直接当作传感器过曝或印刷软打样。未包含 CMYK 印刷纸张/油墨模拟；显示器本身仍需要正确校准。

Ctrl+K 打开色卡标定。导入 CSV（name,r,g,b，参考为适用条件下 sRGB 0–255；可加 role=train/validation），支持 8–96 色。可逐块取样或两点框选规则网格；透视明显时优先逐块取样。拟合使用全尺寸中心区域中值，排除明显反光/剪裁，至少 8 个有效训练色；声明验证集时还至少需要 3 个有效验证色。界面提供 RGB RMSE、名义 ΔE00 和门槛结果，通过后才能应用。

校正为线性 RGB 3×3 矩阵，处在反相/白平衡/黑白场/曝光之后，曲线、HSL 等之前。支持强度、导入/导出与参数保存；条件变化后需要重新检查。校正不替代扫描仪 LUT ICC、光谱标定或不同设备间的实测认证；本次合成演示和数值回归不构成色彩实测认证。使用真实色卡时应采用对应版本、光源与测量条件的参考值。

10. 单张、整条胶片与多照片导航

顶部「自动识别」依赖片基边缘、片夹与真实帧间隙；证据不足会保留完整图像，「单张」明确避免误切，「整条」进入帧处理。自动识别不能保证所有片夹、黑边和曝光都正确。Ctrl+Shift+R 可手动增删、移动、缩放、排序片框并设切出方向；应用前会提示覆盖范围，重大调整前建议另存工程。

底部「当前胶片帧」在一份原片内切帧；「本次照片」在多个文件间切换。多选拖入会把照片登记到库并进入底部导航，重复路径去重，不能支持的项目会计数忽略。未打开的大图可用嵌入/缓存预览，缺少预览则在打开后生成。

跨文件切换保存并恢复每张独立曝光、几何、局部编辑及逐帧状态；不会把上一张的曝光悄悄套到下一张。「切帧沿用当前调色」作用于同一条胶片内部；关闭可恢复各帧独立参数。「应用到全部帧」显式更新整卷模板，使用前需确认几何等字段是否适合所有帧。

整卷可导出全部帧，每帧附配方并生成 manifest；取消在当前帧结束后生效，保留已完成输出。原生 RAW 解码等底层调用不能即时中断，退出或取消时可能需要等待。

11. 批量工作流 C（包含独立准备 A 与分组/校样 B）

入口为底部「批量处理…」或 Ctrl+Shift+B。三个页面分别是「1 · 清单与准备」「2 · 规则与分组同步」「3 · 校样与导出」。它适用于多文件逐张反相、同卷风格同步和整条文件的批次组织。每个文件既可代表一张照片，也可代表一条有多帧的扫描。

11.1 独立准备

多选文件建批次后，先为输入设置「每文件单张」「整条」或「自动识别」。默认「各自自动反相；保留已有编辑」会给每张独立估片基与跨度，已修过的图默认保留编辑。依次「① 检查原片」「② 独立准备」，核对错误、帧数和状态；单张失败可单独修正并重试。明确执行「重新准备选中…」才会替换对应旧编辑，会提示受影响清单。

清单左侧「导出」复选框决定后续导出候选；行高亮选择决定当前检查/准备/同步/校样等操作对象，两种选择不可混淆。Ctrl/Shift 多选用于指定行。准备/同步还考虑勾选、跳过及当前筛选；建议每次明确选中目标。

11.2 分组与字段同步

可以手工分组或按规则重新分组。每组挑参考图在主窗口精修，再保存组参考。选择要统一的字段后执行「③ 应用组风格」，确认清单与字段；也可只做独立反相而不共享风格。

可同步胶片/反相风格、白平衡、曝光、黑白场/曲线/HSL、输出空间与色卡配置。曝光支持参考绝对值或相对增减，同时可设每图 EV 修正。裁切、校直、透视、片边、局部修复和平场不跨图复制。工作空间不同应分组并使用匹配参考。共享实测片基必须明确指定可信参考并确认，默认仍各自估片基；不同光路、胶片或曝光不应盲目共享。

11.3 4/9 图校样与人工复核

第三页提供 4 图/9 图前后校样、刷新选中校样与「标记选中已复核」。校样供比较偏色、曝光、边界、方向和风格；需要精修时在第一页选一张「打开选中微调」，回来后刷新并重新复核。底部「复核当前照片」和 Shift+R 也能完成符合条件的文件复核。

复核以文件为单位。整条扫描的批次校样只显示代表预览，不自动把所有帧展开；导出全帧前必须打开该文件逐帧检查。勾选「加入队列前要求人工复核」只是门槛，不会代替人看图。未准备、未校验或有错误的项不能强制标为通过，参数变化后需要重新复核。

11.4 模板、停靠、恢复与撤销

设置可保存为模板，再应用到新批次；应用模板不会自动导出，仍须核对输入、参考和输出。流水线可在独立准备后、同步后等阶段停靠，让人工检查后继续。暂停准备/同步在当前照片完成后生效，暂停导出在当前帧结束后生效。批次持久保存，重开后先检查原片身份，再继续；恢复底部导航可用「载入底部导航」。

支持失败项重试和最近一次覆盖/同步撤销。撤销编辑不会改动已冻结任务；库备份恢复后的批次会暂停、要求重新核对与复核。程序崩溃、断电或磁盘错误不能保证当前帧即时完成，需根据错误和持久记录恢复。

11.5 冻结队列、多轮导出与自动汇总

第三页选择批次输出目录、命名模板（默认 {source}-f{frame:04d}-positive）、是否包含每文件全部帧、按组子目录及人工复核要求，先保存设置，再「固定参数并加入导出队列」，最后「开始 / 继续本批次导出」。入队和开始写文件是两步。

入队固定原片身份、帧布局与参数；后来改变筛选、评级、风格或曝光都不修改旧任务。要用新参数再输出，请「新建下一轮导出…」并重新复核、入队，旧轮次与旧成品保留。任务按顺序执行，以照片/任务独立子目录组织成品；结束后自动生成联系表、batch-summary.json、参数与失败汇总，可点「打开最新汇总」。有失败时应检查汇总，不能只看部分 TIFF 已生成就当作整批成功。

续导核对已完成 TIFF/配方 SHA256，通过才跳过；已改动成品、原片不符、暂存缺失或处理引擎版本改变时会拒绝不安全续写。旧 rc13 队列保留，但正式版版本元数据改变会改变引擎签名：应使用旧版完成旧冻结任务，或在正式版新建一轮。新版本不承诺跨引擎继续旧任务。

12. 筛选、评级与快捷键

底部与批量清单支持文件名/路径/分组搜索、分组、状态、最低星级及精选/弃选/未标记筛选。零结果保留当前图与编辑；清除筛选恢复导航。筛选不自动改变导出勾选，要只输出结果需显式点「仅勾选筛选结果」再冻结队列。弃选/跳过不进入新任务；已有冻结任务保持原内容。未选行时校样/复核限定显示项，零结果不扩大为全批。

13. 工程、配方、照片库与备份迁移

.filmproj 保存原片身份、输入模式/片框、当前帧、逐帧参数、整卷模板、色彩/色卡与平场等。工程引用原片，优先以相对路径定位，缺失时允许重新定位并核验完整 SHA256。错误原片、损坏工程会报错并保留当前编辑。大型文件校验会增加读盘时间，工程不包含撤销历史和画布缩放位置。

JSON 配方适合复用调色，不重建完整整条帧布局；默认载入时保留当前片基、测光和平场，只有明确勾选才完整载入。工程、配方与自动会话用途不同，自动保存不会覆盖手动工程。旧格式工程/配方由当前读取器兼容，新功能工程可能被旧软件拒绝或无法完整解释；建议旧工程保留原件，在新版另存，四角透视可用工程 v7/配方 v5 表达。

照片库把原片路径、标签评级、独立编辑快照与任务保存在 studio/library.sqlite3 及关联目录。按 Ctrl+I 可管理与备份。库备份 .filmbackup 不包含原片和成品；恢复前自动保留旧库的恢复备份，并验证结构与校验，未完成任务转暂停。完整环境迁移应先关闭软件和子进程，再备份整个用户数据目录、原片与输出目录；不要只在库运行时复制 sqlite 文件。

「当前整卷工程与原片迁移包」会明确打包当前原片和工程，可把单卷交给另一台电脑，解包到新建独立文件夹并核验；与不包含原片的照片库备份不同。留意 RAW 很大，迁移包需要额外空间。

从 rc13/旧便携版升级：先保存工程和库备份、关闭旧版，安装到新空目录。最稳妥是直接打开旧工程，或用库备份恢复。若要完整复制旧 data 到安装版用户数据位置，必须先备份双方并确认目标没有需要保留的新编辑，复制到空目标，不能合并两个活动照片库。安装程序不自动扫描其他盘、不搬移旧库、不删除旧安装。旧成品、原片及旧包作为回退基线保留。

14. TIFF 导出与成品交接

单帧、整卷、照片库队列与批次最终生成 16bit RGB TIFF，并附 JSON 配方/清单。sRGB 适合一般兼容交接，Adobe RGB 或 ProPhoto 适合明确支持色彩管理的后续编辑流程；接收方必须正确读取 ICC。可按命名白名单使用 {source}、{frame:04d}、{roll}、{date}，不允许任意路径表达式。不同出口的默认命名和组织方式不同，请先核对预览/设置。

全尺寸导出重新处理，不把界面预览图放大当作成品；100% 检查、局部上下文与预览缓存用于保持处理一致性。直接另存的同名文件由保存对话框处理确认，用户应选择新名字；队列采用独立任务目录和已有文件校验，拒绝无条件覆盖。为了保留各轮结果，建议总是新建导出目录/轮次。

完成后至少抽查 TIFF 尺寸、方向、裁切、细节、ICC 与 JSON 对应。整条检查首尾帧及容易切错的边界；批次阅读汇总中的错误。磁盘满或权限错误时保留已完成文件，先处理空间/权限，再按任务状态恢复或新建任务。

15. 性能与内存设置

「视图 → 切图缓存」支持关闭、512 MiB、1 GiB（默认）、2 GiB和清空。默认预算限制保留的原图缓存数组，并非全进程内存上限。初始分析、预览/缩略图、当前图、解码/处理临时数组、Qt 与独立批量/导出进程另计。清空缓存保留当前编辑，关闭缓存后首次切回会重新读取。

rc12 本机两张 NEF 在所需缓存齐全时，往返切换约 0.33–0.36 秒；首次打开、淘汰或参数不匹配不适用这个数字。rc13 本机单次邻图测试中，空闲预加载约 1.95 秒后首次切换由约 5.22 秒降到约 3.38 秒，前台 RAW 解码由一次变为零；原片身份核验、初始分析及独立编辑恢复仍执行。它不是多机平均值或无条件速度承诺；正式版沿用该实现，本轮没有重新宣称获得一组新的真实 RAW 性能测量。

相邻预加载在空闲约 800 ms 后，以低优先级只准备浏览方向的一张不可变原图，不安装到当前引擎、不套用其他照片的参数。超预算、尺寸不能可靠判断、原片变化或取消后不发布结果；部分未知尺寸容器不预加载但可正常打开。实际超大 FFF 预计原图约 1.80 GB，在默认 1 GiB 下跳过预加载，不代表不能打开。

切图、调色、批量准备、导出或退出会取消旧预加载；底层 RAW 解码本身不能即时中断，需等调用返回。独立批量准备/导出默认逐源释放，不启用整图缓存。内存紧张可先关闭预加载、降低缓存、暂停后台导出并只开一个编辑窗口；大图仍要满足实际解码和处理峰值。

16. 常见问题

解压后启动不了

确认已经完整解压、没有从 ZIP 预览中直接运行，app/runtime 未分离。运行「启动诊断.cmd」检查 manifest、依赖导入、Qt 窗口及合成演示工程恢复；报告在实际用户数据目录的 startup-diagnostics.json，控制台会输出诊断内容。清单发现缺失/变更时重新解压可信包，SHA256 用于完整性核对。若文件在启动前被安全软件拦截，保留实际检测名、文件名与 SHA256，诊断可能尚来不及执行；不要把运行时签名当成安全认证。

16bit TIFF 反相偏暗、灰雾或颜色奇怪

先核对它是线性还是经过 gamma 编码，以及嵌入 ICC 是否受支持；再核对模式、片基和跨度。重复转换或把编码图当线性都会影响密度。过曝通道、严重欠曝和 JPEG 量化无法通过换色域恢复。

整条识别错、校样只显示一张

手动指定单张/整条并在片边/切帧中修正框。批次校样每个文件只显示代表图；整条需要在主窗口逐帧检查后再按文件复核。

选中过滤结果，为什么仍有其他文件导出

筛选改变显示，不自动清除隐藏项的导出勾选。需要显式「仅勾选筛选结果」；已冻结任务保持原参数和范围，要调整它应新建一轮。

提示未准备、校验或复核

回第一页明确选行，先「检查原片」，缺少编辑则「独立准备」；解决错误，完成校样/逐帧检查，第三页「标记选中已复核」，再固定参数入队并开始导出。

升级后旧队列不继续、原片移动后库找不到

旧冻结任务绑定引擎与原片身份，版本变化可能拒绝续导。保留旧版完成旧任务或在新版新建任务。普通工程可重新定位且校验原片；没有承诺整个照片库和所有队列路径的自动批量重定位。迁移时尽量保留原片与输出相对/绝对路径。

取消不立即生效、内存超过 1 GiB

取消按当前计算安全边界处理，RAW 原生解码和当前帧不能立刻停下。1 GiB 是保留原图缓存预算，进程总内存和后台导出另计，属预期边界。

卸载后编辑还在、移动便携目录后入口失效

安装版按设计保留用户数据，重装后仍可使用；若要主动清理，应先备份并由用户自行管理。便携版移动后用 CMD 重新生成本机快捷方式，原片和输出位置仍需核对。

17. 验证边界与已知限制

正式版以已验收 rc13 为功能基线，处理算法、暗房布局及批量工作流保留。本轮重点为发行元数据、数据位置、安装/卸载与打包验证；具体运行结果以随包 RELEASE-VALIDATION-3.0.0.md 为准，历史 rc13 NEF 全尺寸 TIFF 69,075,006 个 uint16 样本一致性属于上一轮证据。

当前没有完成所有相机/RAW 容器、其他 Windows 电脑、高 DPI 组合、安全软件认证、长时间真实生产负载或设备色彩实测认证。不承诺自动切帧、自动反相和通道修复对所有底片都正确。数值回归与合成样例不能替代实际整卷人工复核。

原生 RAW 解码不可即时中断；部分容器不预加载；极大原图需要足够内存和磁盘。局部修复、透视和色卡有前述边界；输入 LUT ICC、CMYK、BigTIFF 等未保证。库备份不带原片，旧引擎冻结队列不保证跨版本续导。故障后按帧恢复，不从一帧内部的某个像素接着导出。

软件包不包含私人原片、库、缩略图、实际工程、成品或 validation 目录，仅附合成样例。第三方许可保留，发行包及应用未签名。请把正式版、SHA256 清单、自己的工程备份和原片分开保存，以便核对与恢复。

18. 推荐完整工作流

一张照片：原片备份 → 核对输入编码/工作空间 → 选择反相模式 → 片基/测光 → 明暗与白平衡 → 曲线/HSL → 输入区域/几何 → 局部修复与 100% 检查 → 保存工程 → 选择 TIFF 输出空间 → 新目录导出并抽查。

一批照片：多图导入 → 设置输入与停靠 → 检查原片 → 独立准备 → 按需要分组/参考字段同步 → 4/9 图校样与逐图微调 → 整条逐帧检查 → 标记人工复核 → 核对勾选/输出/命名 → 固定参数入队 → 开始导出 → 查看汇总与抽查 → 备份用户数据、工程、原片和成品。
