FilmInvert Native 3.0.0 正式版 · Windows x64

完整独立运行时，不需要另外安装 Python 或 Qt。仅为当前 Windows 用户安装。
请选择新的空目录；安装程序拒绝覆盖非空目录，不直接升级或删除旧安装。
默认安装：%LOCALAPPDATA%\Programs\FilmInvert Native\3.0.0
用户数据：%LOCALAPPDATA%\FilmInvertNative\data
默认输出：%LOCALAPPDATA%\FilmInvertNative\exports（可在软件中改选）
帮助 → 打开用户数据目录，可定位会话、settings.ini 和 studio 照片库/队列。

卸载只移除安装文件与本次安装的入口。用户数据、原片、工程和成品予以保留。
卸载前请关闭软件及导出进程；不要把自己的文件存入 app 或 runtime 等安装文件路径。
旧版迁移：关闭两版并备份，打开旧 .filmproj，或通过照片库备份/恢复。
完整迁移 data 时请先备份并确认目标尚未有新编辑，不合并覆盖两个正在用的库。
旧冻结队列可能因引擎版本校验拒绝续导，应保留旧版完成旧任务或新建导出轮次。

安装包和应用未获得发行者数字签名。官方 Python 文件保留上游原有签名。
校验和不等于安全软件认证。本次未进行其他电脑、所有相机或设备色准认证。
