# FilmInvert Native 3.0.1

2026-10-28 · Windows x64

- 新增简体中文 / English 语言选择，可从主工具栏或「视图 → Language / 语言」切换。
- 切换立即更新主窗口和已打开的工具窗口，退出后保留语言选择。
- 英文覆盖调色、照片库、批量工作流、校样、切帧、裁切透视、局部修片和色卡标定的应用界面文字。
- 文件名、路径、胶卷标签、分组名等用户内容保持原文；编辑参数、撤销历史、批次和导出队列保持不变。
- 新增 `README.en.md` 英文项目介绍和 `README.en.html` 离线说明，英文界面的帮助入口打开英文说明。
- 新增英文便携启动入口 `Launch FilmInvert.cmd`，保留中文启动入口。

## English

Adds an instant Simplified Chinese / English interface switch in the toolbar and View menu. The selected language is remembered. Open photos, edits, undo history, batch state and queued snapshots remain intact. User filenames and labels retain their original text. Includes an English introduction, offline guide and portable launcher.

This update changes presentation and language preferences; image-processing algorithms and project formats are unchanged. Low-level decoder diagnostics and existing reports may retain their original language.
