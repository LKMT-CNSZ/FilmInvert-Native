# FilmInvert Native

**在本机完成胶片反相、逐帧精修与批量交付。**

A local film negative conversion and editing tool for Windows. Supports color and black-and-white negatives, RAW files, film strip scans, independent editing of multiple images, batch proofing and export, and 16-bit TIFF output with embedded ICC profiles. Available in installer and portable editions.

FilmInvert Native 是一款面向 Windows 的胶片数字化修片工具，适用于相机翻拍和扫描得到的彩色负片、黑白负片及整条胶片图像。从片基取样、密度域反相、明暗与色彩调整，到切帧、几何校正、局部修复和 16bit TIFF 导出，可以在同一个原生桌面界面中完成。

软件采用黑白灰的极简“暗房”布局：中央大图、右侧调色、底部照片与胶片帧导航。既适合逐张处理，也支持把一批照片组织成可暂停、可恢复、经过人工复核的导出流程。

**当前版本：3.0.0 · Windows x64 · 安装版 / 免安装版**

## 适合哪些场景

- **相机翻拍负片**：直接打开受支持的 RAW，完成去色罩、反相和调色。
- **扫描整条胶片**：识别或手动设置片框，逐帧调整、校直并导出。
- **整理同一胶卷**：各张独立准备，再按需要统一参考风格与选定参数。
- **批量修片交付**：通过校样、人工复核、冻结队列和自动汇总，管理多文件、多帧和多轮输出。
- **保留后续调整空间**：保存工程、配方与照片库编辑，重新打开时继续修片。

## 主要功能

### 胶片反相与调色

支持彩色负片、黑白负片和正片处理模式。彩色负片在密度域中扣除片基，结合密度跨度、反差与胶片风格矩阵完成反相；提供自动估计和手动取样，便于应对不同胶片、曝光与翻拍条件。

可调整曝光、黑白场、白平衡、通道增益、曲线、八色 HSL 和饱和度，并提供欠曝通道修复、孤立尘点处理、暗角与平场校正。自动结果可以作为调色起点，重要画面仍应结合原片与全尺寸结果检查。

### 切帧与几何校正

- 单张、整条与自动识别三种输入方式。
- 手动增加、删除、移动、缩放和排序片框。
- 自由或固定比例裁切、90° 旋转和小角度校直。
- 多条水平 / 竖直参考线加权校直，支持端点调整与撤销。
- 片边倾角建议、手动画线，以及当前帧 / 同条角度应用。
- 四角透视校正与输出比例设置。

输入片框与成品裁切分别保存：可以先从整条扫描中确定每一帧，再对每帧独立构图。

### 局部精修

提供手动仿制修复、曝光笔刷和线性渐变，可调整半径、羽化与强度，用于处理尘点、划痕及局部明暗。局部编辑随参数保存，批次风格同步不会复制其他照片的修复位置。

仿制修复使用图像内的实际来源区域，不包含生成式补画或红外除尘。

### 色彩管理与色卡

支持线性 sRGB / ProPhoto 工作空间，以及 sRGB、Adobe RGB (1998)、ProPhoto RGB 的 TIFF 输出与 ICC 嵌入。提供输入编码选择、受支持的嵌入 ICC 读取、显示器 RGB ICC 和输出 RGB 色域预览。

色卡工作台支持参考 CSV、逐块或网格取样、训练 / 验证色块划分，以及线性 RGB 3×3 校正矩阵拟合。可查看误差与验证结果，保存或复用校正配置。

### 多照片独立编辑

多张照片拖入后进入底部导航。跨文件切换时保存并恢复各自的调色、几何与局部编辑；整条胶片还可以切换到底部帧导航，逐帧检查。

照片库支持搜索、分组 / 胶卷标签、0–5 星评级、精选与弃选。编辑和评级保存在软件数据中，不回写原片 EXIF。

### 完整批量工作流

批量工作流包含独立准备、分组同步、校样复核与导出三个阶段：

1. **独立准备**：每张照片分别估计片基与密度跨度，默认保留已有编辑。
2. **分组同步**：为各组指定参考图，仅同步勾选字段；曝光可使用绝对值或相对增减，并保留每图 EV 修正。
3. **校样复核**：使用 4 / 9 图前后校样比较，逐图微调后标记人工复核。
4. **冻结入队**：固定当时的原片身份、帧布局、参数与命名，再开始导出。
5. **恢复与汇总**：支持模板、阶段停靠、暂停恢复、失败重试、多轮导出和自动联系表 / 参数 / 失败汇总。

裁切、透视、片边、局部修复和平场不会通过批次风格同步跨图复制。已冻结的任务也不会随着后续调色或筛选而改变。

### 工程与 16bit TIFF 交付

`.filmproj` 工程保存输入设置、片框、逐帧编辑、整卷模板及相关色彩参数；JSON 配方用于记录与复用调色。成品支持单帧、整卷和队列导出，输出 16bit RGB TIFF，并附配方或清单。

照片库支持备份与恢复；单卷迁移包可明确打包工程和原片。普通工程与照片库备份不会自动包含原片，迁移时需要分别保留原片和成品。

## 快速上手

### 完成第一张照片

1. 按 `Ctrl+O` 打开原片，或直接拖入画布，确认单张 / 整条模式。
2. 核对输入编码与工作空间，选择彩色负片、黑白负片或正片模式。
3. 检查片基和测光，调整曝光、反差、黑白场与白平衡。
4. 按需要处理曲线、HSL、裁切、校直、透视与局部瑕疵。
5. 使用 `Ctrl+1` 检查全尺寸结果，按 `Ctrl+Alt+S` 保存工程。
6. 选择输出空间和目录，按 `Ctrl+Shift+S` 导出 TIFF 与配方。

### 完成一批照片

**多图导入 → 检查原片 → 独立准备 → 按需分组同步 → 校样与微调 → 人工复核 → 固定参数入队 → 开始导出 → 查看汇总。**

批量入口为底部「批量处理…」或 `Ctrl+Shift+B`。整条文件在批次校样中只显示代表图，导出全部帧前需要在主窗口逐帧检查。

筛选只改变显示范围，不自动改变导出勾选。只导出当前筛选结果时，请显式点击「仅勾选筛选结果」后再入队。

## 输入格式与运行环境

| 类别 | 支持范围 |
| --- | --- |
| 平台 | Windows 10 / 11 x64 发行目标 |
| 相机 RAW | 包括 NEF、CR2 / CR3、ARW、DNG、RAF、ORF、RW2 等；实际兼容性取决于随包 rawpy / LibRaw 与具体机型、容器 |
| 扫描与常规图像 | TIFF、PNG、JPEG、BMP、WebP；部分 FFF / 3FR 可通过其 TIFF 容器读取 |
| 色彩输入 | 明确的 RGB 编码，以及受支持的 v2 / v4 RGB matrix/TRC ICC |
| 输出 | 16bit RGB TIFF、ICC、JSON 配方及整卷 / 批次清单 |

16bit TIFF 使用专用读取路径。BigTIFF、tiled、planar 分离、CMYK、LUT 输入 ICC 等不在保证范围内。扩展名受支持也不代表所有相机、压缩方式和文件变体都已验证。

日常修片与导出在本机离线完成，不需要上传照片或登录账户。界面基于 Qt Widgets，不依赖浏览器或本地 HTTP 服务。

## 性能设置

「视图 → 切图缓存」可选择关闭、512 MiB、1 GiB 或 2 GiB，并支持清空与关闭相邻预加载。

默认 **1 GiB 限制保留的原图缓存，并非整个进程的内存上限**。当前图、解码与处理临时数组、预览、Qt 和独立导出进程会另外占用内存。

历史本机测试中，两张 NEF 在缓存齐全时往返约 0.33–0.36 秒；相邻原图空闲预加载约 1.95 秒后，首次邻图切换由约 5.22 秒降至 3.38 秒。以上为特定样本的本机观测，身份核验、分析与独立编辑恢复仍会执行，不作为其他机器的速度保证。

原生 RAW 解码不能即时中断，部分未知尺寸容器不预加载，超出预算的大图会跳过预加载，但仍可按正常路径打开。
