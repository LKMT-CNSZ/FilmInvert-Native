# FilmInvert Native

**3.1.1 正式版：**新增片边排除测光、单张高光/阴影/黑白场、局部色调映射、多曝光 HDR 合成、线性 ICC float32 HDR TIFF 和 Windows 原生 HDR 预览。用法及限制见 [HDR 指南](HDR-GUIDE.md)。HDR 显示目前为实验功能，已验证 FP16 通道和 SDR 拒绝，HDR 硬件视觉验收尚待完成。

**本版更新：**完整中英文深色安装器、安装后验证及旧版清理；HDR 屏幕适配、持久调色和三种预设；Ultra HDR JPEG 增益图导出。

**在本机完成胶片反相、逐帧精修与批量交付。**

FilmInvert Native 是一款面向 Windows 的胶片数字化修片工具，适用于相机翻拍和扫描得到的彩色负片、黑白负片及整条胶片图像。从片基取样、密度域反相、明暗与色彩调整，到切帧、几何校正、局部修复和 16bit TIFF 导出，可以在同一个原生桌面界面中完成。

软件采用黑白灰的极简“暗房”布局：中央大图、右侧调色、底部照片与胶片帧导航。既适合逐张处理，也支持把一批照片组织成可暂停、可恢复、经过人工复核的导出流程。

## 适合哪些场景

- **相机翻拍负片**：直接打开受支持的 RAW，完成去色罩、反相和调色。
- **扫描整条胶片**：识别或手动设置片框，逐帧调整、校直并导出。
- **整理同一胶卷**：各张独立准备，再按需要统一参考风格与选定参数。
- **批量修片交付**：通过校样、人工复核、冻结队列和自动汇总，管理多文件、多帧和多轮输出。
- **保留后续调整空间**：保存工程、配方与照片库编辑，重新打开时继续修片。

## 主要功能

### 胶片反相与调色

支持彩色负片、黑白负片和正片处理模式。彩色负片在密度域中扣除片基，结合密度跨度、反差与胶片风格矩阵完成反相；提供自动估计和手动取样，便于应对不同胶片、曝光与翻拍条件。

可调整曝光、黑白场、白平衡、通道增益、曲线、八色 HSL 和饱和度，并提供欠曝通道修复、孤立尘点处理、暗角与平场校正。自动结果可以作为调色起点，重要画面仍应结合原片与全尺寸结果检查。

### 切帧与几何校正

- 单张、整条与自动识别三种输入方式。
- 手动增加、删除、移动、缩放和排序片框。
- 自由或固定比例裁切、90° 旋转和小角度校直。
- 多条水平 / 竖直参考线加权校直，支持端点调整与撤销。
- 片边倾角建议、手动画线，以及当前帧 / 同条角度应用。
- 四角透视校正与输出比例设置。

输入片框与成品裁切分别保存：可以先从整条扫描中确定每一帧，再对每帧独立构图。

### 局部精修

提供手动仿制修复、曝光笔刷和线性渐变，可调整半径、羽化与强度，用于处理尘点、划痕及局部明暗。局部编辑随参数保存，批次风格同步不会复制其他照片的修复位置。

仿制修复使用图像内的实际来源区域，不包含生成式补画或红外除尘。

### 色彩管理与色卡

支持线性 sRGB / ProPhoto 工作空间，以及 sRGB、Adobe RGB (1998)、ProPhoto RGB 的 TIFF 输出与 ICC 嵌入。提供输入编码选择、受支持的嵌入 ICC 读取、显示器 RGB ICC 和输出 RGB 色域预览。

色卡工作台支持参考 CSV、逐块或网格取样、训练 / 验证色块划分，以及线性 RGB 3×3 校正矩阵拟合。可查看误差与验证结果，保存或复用校正配置。

### 多照片独立编辑

多张照片拖入后进入底部导航。跨文件切换时保存并恢复各自的调色、几何与局部编辑；整条胶片还可以切换到底部帧导航，逐帧检查。

照片库支持搜索、分组 / 胶卷标签、0–5 星评级、精选与弃选。编辑和评级保存在软件数据中，不回写原片 EXIF。

### 完整批量工作流

批量工作流包含独立准备、分组同步、校样复核与导出三个阶段：

1. **独立准备**：每张照片分别估计片基与密度跨度，默认保留已有编辑。
2. **分组同步**：为各组指定参考图，仅同步勾选字段；曝光可使用绝对值或相对增减，并保留每图 EV 修正。
3. **校样复核**：使用 4 / 9 图前后校样比较，逐图微调后标记人工复核。
4. **冻结入队**：固定当时的原片身份、帧布局、参数与命名，再开始导出。
5. **恢复与汇总**：支持模板、阶段停靠、暂停恢复、失败重试、多轮导出和自动联系表 / 参数 / 失败汇总。

裁切、透视、片边、局部修复和平场不会通过批次风格同步跨图复制。已冻结的任务也不会随着后续调色或筛选而改变。

### 工程与 16bit TIFF 交付

`.filmproj` 工程保存输入设置、片框、逐帧编辑、整卷模板及相关色彩参数；JSON 配方用于记录与复用调色。成品支持单帧、整卷和队列导出，输出 16bit RGB TIFF，并附配方或清单。

照片库支持备份与恢复；单卷迁移包可明确打包工程和原片。普通工程与照片库备份不会自动包含原片，迁移时需要分别保留原片和成品。

## 快速上手

### 完成第一张照片

1. 按 `Ctrl+O` 打开原片，或直接拖入画布，确认单张 / 整条模式。
2. 核对输入编码与工作空间，选择彩色负片、黑白负片或正片模式。
3. 检查片基和测光，调整曝光、反差、黑白场与白平衡。
4. 按需要处理曲线、HSL、裁切、校直、透视与局部瑕疵。
5. 使用 `Ctrl+1` 检查全尺寸结果，按 `Ctrl+Alt+S` 保存工程。
6. 选择输出空间和目录，按 `Ctrl+Shift+S` 导出 TIFF 与配方。

### 完成一批照片

**多图导入 → 检查原片 → 独立准备 → 按需分组同步 → 校样与微调 → 人工复核 → 固定参数入队 → 开始导出 → 查看汇总。**

批量入口为底部「批量处理…」或 `Ctrl+Shift+B`。整条文件在批次校样中只显示代表图，导出全部帧前需要在主窗口逐帧检查。

筛选只改变显示范围，不自动改变导出勾选。只导出当前筛选结果时，请显式点击「仅勾选筛选结果」后再入队。

## 输入格式与运行环境

| 类别 | 支持范围 |
| --- | --- |
| 平台 | Windows 10 / 11 x64 发行目标 |
| 相机 RAW | 包括 NEF、CR2 / CR3、ARW、DNG、RAF、ORF、RW2 等；实际兼容性取决于随包 rawpy / LibRaw 与具体机型、容器 |
| 扫描与常规图像 | TIFF、PNG、JPEG、BMP、WebP；部分 FFF / 3FR 可通过其 TIFF 容器读取 |
| 色彩输入 | 明确的 RGB 编码，以及受支持的 v2 / v4 RGB matrix/TRC ICC |
| 输出 | 16bit RGB TIFF、ICC、JSON 配方及整卷 / 批次清单 |

16bit TIFF 使用专用读取路径。BigTIFF、tiled、planar 分离、CMYK、LUT 输入 ICC 等不在保证范围内。扩展名受支持也不代表所有相机、压缩方式和文件变体都已验证。

日常修片与导出在本机离线完成，不需要上传照片或登录账户。界面基于 Qt Widgets，不依赖浏览器或本地 HTTP 服务。

## 性能设置

「视图 → 切图缓存」可选择关闭、512 MiB、1 GiB 或 2 GiB，并支持清空与关闭相邻预加载。

默认 **1 GiB 限制保留的原图缓存，并非整个进程的内存上限**。当前图、解码与处理临时数组、预览、Qt 和独立导出进程会另外占用内存。

历史本机测试中，两张 NEF 在缓存齐全时往返约 0.33–0.36 秒；相邻原图空闲预加载约 1.95 秒后，首次邻图切换由约 5.22 秒降至 3.38 秒。以上为特定样本的本机观测，身份核验、分析与独立编辑恢复仍会执行，不作为其他机器的速度保证。

原生 RAW 解码不能即时中断，部分未知尺寸容器不预加载，超出预算的大图会跳过预加载，但仍可按正常路径打开。

## 问题反馈

提交 Issue 时，请尽量附上软件版本、Windows 版本、输入格式 / 相机型号、复现步骤、预期结果和实际结果。启动问题可补充「启动诊断.cmd」生成的报告；提交前请检查并移除个人路径等隐私信息。需要提供原片时，优先使用能够复现问题的合成或可公开样例。

## 主窗口直接 HDR 调色

工具栏「主画布 HDR」在原画布开启 HDR；需先开启 Windows HDR。可直接调整曝光、颜色、曲线及局部影调，使用原有取样、缩放、撤销和照片导航。再次点击回到 SDR；系统 HDR 关闭或显示设备失效会自动回退。显示开关不改配方或导出格式。参考白默认跟随 Windows，可在 HDR 显示适配中手动设置，SDR 高光柔化不参与 HDR 呈现。

直方图为 SDR 导出统计；HDR 开启时暂不可用 SDR 输出色域预览和越界叠加。大图 HDR 100% 预览受 768 MB 临时预算保护，超限自动回到适应窗口；导出尺寸不受影响。HDR 硬件视觉验收仍待完成。

显示器报告峰值缺失、低于 80 nit 或高于 10000 nit 时，HDR 预览暂按 1000 nit 估计，状态栏会明确提示。请使用 Windows HDR 校准核实屏幕能力；该估计不改动调色参数或 HDR 导出数据。

## 统一 TIFF 导出

顶部「导出 TIFF…」及 Ctrl+Shift+S 的保存窗口，在「保存类型」中提供 SDR TIFF - 16bit 和 HDR TIFF - Float32。主画布 HDR 开启时默认选中 HDR；可手动切回 SDR。HDR 使用浮点线性 TIFF、嵌入线性 ICC 并保留超过参考白的亮部。文件菜单原有 HDR 入口也使用此窗口。普通整卷／批量导出仍为 SDR。

## Windows HDR 成品导出

「导出 TIFF / HDR…」新增 Windows HDR - JPEG XR (*.jxr)。主画布 HDR 开启时默认选中 JXR；HDR TIFF 仍可选，文件菜单「导出线性 HDR TIFF」默认选择 TIFF。JXR 使用 Windows 原生 WIC 编码器，工作空间转换为线性 sRGB 后按 203/80 缩放为 scRGB 绝对亮度单位，保留超过 1 的数据，不烘焙当前屏幕的高光肩部。

JXR 采用编码器的 Lossless 选项，但浮点预处理存在精度量化，不承诺原浮点位逐字节一致；HDR TIFF 继续用作浮点编辑母版。JXR 面向 Windows HDR 查看，不能保证所有平台都能打开。不同查看器仍可能采用不同高光映射，需在目标软件实测。原生编码/解码的数值和保存窗口路径验证已通过。用户已用 Windows「照片」打开同图 JXR，反馈亮度更接近 FilmInvert 预览；这是用户目视反馈，尚未进行仪器测量或跨设备验收。JXR 暂不支持重新导入 FilmInvert，继续编辑请保留工程和 TIFF 母版。

## 首次查看显影与帧导航

新导入的负片在底部帧导航中先显示带色罩的实际原片。每帧首次查看及每次切换到该帧时播放 1.6 秒从左向右柔边显影，RGB 同步还原；动画结束后，该帧缩略图更新为当前正片。其余未查看帧仍显示原片。已显影记录按原片内容、输入方式和帧位置保存到当前用户配置，每次切到另一帧都会重播；重开图片、恢复已有编辑或工程时不重播；修改原片内容或重新划分的帧使用新身份。

鼠标、滚轮、键盘或调色操作可跳过动画，并显示当前正片；关闭「视图→首次查看显影动画」或 Windows 动画时直接显示正片。正像模式不播放。不改动调色参数、直方图、取样或导出像素。适应窗口与 100% 可见区域支持过渡，单次原片预览预算 210 万像素；HDR 临时显示缓存上限 8 MP，超限直接显示结果。本功能不增加 DNG 压缩格式的解码兼容性。

继续沿用 rc7 的缓存纹理、局部柔边合成、HDR 后台准备和 16 ms 调度优化。HDR 准备完成后才开始 1.6 秒计时；视口变化或进一步操作可取消准备。过渡使用显示线性 scRGB 缓存，结束恢复实际编辑结果。

软件启动时显示用户提供的红白胶片吉祥物 Logo，以 1.2 秒从左向右柔边显影，随后淡出进入编辑界面。处理模块在后台导入，主窗口在 Qt 主线程创建；初始化超过动画时长时直接衔接，不额外等待另一轮。点击启动画面或 Esc 可跳过，并遵循 Windows 动画设置。启动图片参数仍只打开一次；切图动画继续为 1.6 秒。启动 Logo 的显示尺寸副本随应用提供，原始图片未修改。

## HDR 显示适配与调色

HDR 显示适配与照片调色分开管理。主画布 HDR 只切换显示。右侧「HDR」页显式勾选「启用 HDR 调色」后，亮部强度、起点、过渡、HDR 范围和 SDR 版本设置才参与处理；随每张/每帧编辑、撤销、工程、配方和批次影调同步保存。HDR TIFF 和 JXR 共享同一份浮点调色数据。SDR TIFF 与普通预览使用同一 HDR 数据的 SDR 映射。参数关闭时保留原有算法。

HDR 调色工程版本 9、配方版本 7；旧程序会拒绝新版本。强度为 0 不主动提升亮部，范围上限仍参与高光过渡。扫描或拍摄已丢失的信息无法恢复。

「HDR 显示…」读取当前显示器状态、位深、系统 SDR 参考白与峰值报告；选择窗口所在屏幕对应的 DXGI 显卡，跨屏重新检测/创建显示通道。可按显示器在本机手动设置参考白、峰值。缺失或异常报告使用明确提示的估计值，需结合校准结果复核；不把估计当成实测。显示设置不写入照片、HDR TIFF 或 JXR；JXR 的名义参考白仍按 203 nits 编码，不烘焙某台屏幕的显示转换，不承诺不同查看器外观完全相同。

「对照 SDR 输出」只切换显示，不改照片。HDR 扩展直方图按最亮 RGB 通道统计，0 EV 为名义白；屏幕余量由峰值/参考白计算。「HDR 范围着色」显示黄色 HDR 亮部、红色超屏幕范围。SDR 屏可调 HDR、查看 SDR 版本并导出，无法替代 HDR 屏视觉检查。开启失败弹窗保留详情和 Windows 设置入口。多显示器/多显卡切换已做模拟与本机通道测试，尚未完成跨硬件视觉验收。本版 HDR 显示仍为实验功能。


## 胶片 HDR 预设与 Ultra HDR JPEG

在「HDR」页点击「自然」「通透」「柔和」即可开启 HDR 调色并应用预设。自然温和提升亮部，通透提供更明显的亮部层次，柔和使用较小范围和更长过渡。三者仅调整 HDR 和 SDR 版本参数，保留已有曝光、白平衡、曲线、胶片设置和局部编辑；可撤销，随后可微调。参数随照片/帧、工程、配方与批次影调同步保存。预设不能恢复扫描或拍摄时已经丢失的细节。

点击「导出 TIFF / HDR…」，在保存窗口的文件类型中选择 **Ultra HDR JPEG - SDR + Gain Map**，保存为 `.jpg`。文件内包含带 ICC 的 sRGB SDR 底图和 ISO 21496-1 多通道增益图；普通 JPEG 查看器可显示底图，支持该增益图标准的 HDR 查看器可显示扩展高光。JPEG 为有损格式，保留 HDR TIFF 作为浮点母版；Windows JXR 仍保留。普通 JPEG 查看器与各 HDR 查看器的外观不保证相同，手机、社交平台和转存流程需实测，转存可能移除增益图。此次编码器输出 ISO 增益图，不附加旧版 XMP 增益图。

HDR JPEG 的 SDR 底图采用同一份调色的 SDR 输出。HDR 调色启用时包含「SDR 高光压缩／SDR 曝光」；关闭时沿用原有 SDR 输出。HDR 用 1.0 = 203 nits 的名义参考白，增益图容量由照片内容峰值确定，不烘焙本机屏幕校准，也不采用编码器默认的 10000 nits 容量。导出转换到 sRGB 原色，范围外颜色会裁切；宽色域和无损保存请用 HDR TIFF。JPEG 导出最大边 8192 像素，最高 10000 nits；超限会提示使用 TIFF 或降低范围，不自动缩图。

编码使用 imagecodecs 2026.10.10 官方 Windows wheel 内嵌的 Google libultrahdr 2.0.2，仅随包提供该编码模块与必需辅助模块。构建清单固定官方 URL 与 SHA256，原始许可保留；没有新增系统安装依赖。使用前仍建议检查「对照 SDR 输出」。真实 HDR 观感和跨设备兼容仍待实机验收。
